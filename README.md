# tak-deployment
The Easiest Way (Google Play Store): Have your crew search for "ATAK-CIV" in the Google Play Store and download it like a normal app. This is the civilian version and is perfectly fine for 99% of use cases.

The Official Way (TAK.gov): If they want the absolute latest release or specific plugins, they can register for a free account at tak.gov and download the .apk file directly to their phones.
